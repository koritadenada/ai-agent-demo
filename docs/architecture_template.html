Glossary
The words used on every tab
The port call
Port callOne ship's visit to one port, from arrival to sailing
BuyerShipowner, operator or charterer who pays the port costs
Port agentLocal company that handles the call and pays suppliers
Request case, RFQThe buyer asks several agents to quote for a call
QuotationOne agent's priced answer to the request
AppointmentThe buyer appoints one agent for the call
HusbandryServices for crew and ship: crew change, water, cash
GT, size bandGross tonnage, the ship's size; most dues scale with it
The money
DADisbursement account: the list of port costs of a call
PDA, proformaThe agent's quote before arrival (table proforma)
FDA, evaluationThe agent's final bill after sailing (table evaluation)
Expense lineOne cost on a DA, for example Pilotage 2,730.00 EUR
Final DA packThe FDA as a PDF: summary page, then one invoice per line
Statement of factsTimeline of the call: arrived, berthed, sailed
VerificationAn analyst's check of a line, with a discrepancy type
BenchmarkMedian final cost for the same port, expense and ship size
The data
DMS, CDC, OpAWS copies every database change; Op is I, U or D
BronzeEvery change exactly as received, never edited
SilverCurrent state of each table, with history where kept
GoldJoined business tables with the rules applied
SCD 1, SCD 21 keeps only the latest row, 2 keeps every version
AI FunctionsSQL functions that call a model: parse, classify, extract
Metric viewOne governed definition per KPI: measures and dimensions
Genie agentAnswers plain-language questions on the metric views
